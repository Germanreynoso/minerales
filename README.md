# minerales

App de mineralogía óptica con GeoBot, un tutor socrático (Cátedra de Mineralogía II).

## Setup

1. Copiar `.env.example` a `.env.local` y completar `GROQ_API_KEY` (obtener en https://console.groq.com/keys).
2. Instalar dependencias: `npm install`
3. Levantar en desarrollo: `npm run dev`

> Next.js lee los archivos `.env` solo al arrancar: reiniciá `npm run dev` tras cambiar la key.
